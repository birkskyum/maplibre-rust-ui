# maplibre-ferroui

MapLibre maps in [FerroUI](https://github.com/wieslawsoltes/FerroUI) apps, drawn by mln-rs through
[maplibre-rust-ui](https://github.com/birkskyum/maplibre-rust-ui)'s engine into IOSurfaces that
FerroUI's compositor draws as they are, with nothing copied. It runs on macOS so far.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/ferroui/) has how to use it
and run its example,
[`examples/hello-map`](https://github.com/birkskyum/maplibre-rust-ui/tree/main/ferroui/examples/hello-map).
